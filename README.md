# Femida Forms

Other languages: [Українська](./README.ua.md)

This is a service for complete management of contests within the GoITeens community. It implements the following features:

- creation, editing, and deletion of forms for submitting entries to a contest
- holding voting for the best entries
- vote manipulation detection system
- authentication via Discord OAuth

The service is built using **Typescript, Next.js, TailwindCSS, Shadcn, Supabase**

# Running the Project

1. Clone the git repository

```bash
git clone https://github.com/GoITeens-Projects/femida-forms.git
```

2. Navigate into the created directory

```bash
cd femida-forms
```

3. Install npm dependencies

```bash
npm install
```

4. Set up environment variables using the template

5. Run the project

```bash
npm run dev
```
