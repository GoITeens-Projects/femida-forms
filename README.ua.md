# Femida Forms

Переклад іншими мовами: [English](./README.md)

Це сервіс для повного адміністрування конкурсами всередині спільноти GoITeens. Втілює такий функціонал:

- створення, редагування та видаленя форм для прийому робіт на конкурс
- проведення голосування за найкращі роботи
- систему виявлення накрутки голосів
- авторизація через Discord OAuth

Сервіс побудований з використанням **Typescript, Next.js, TailwindCSS, Shadcn, Supabase**

# Запуск проекту

1. Склонуйте git репозиторій

```bash
git clone https://github.com/GoITeens-Projects/femida-forms.git
```

2. Перейдіть у створену директорію

```bash
cd femida-forms
```

3. Встановіть npm залежності

```bash
npm install
```

4. Задайте змінні середовища за [шаблоном](./.env.template)

5. Запустіть проект

```bash
npm run dev
```
